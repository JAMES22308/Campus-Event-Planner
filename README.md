Campus Event Planner 📅

A React + TypeScript Progressive Web App (PWA) for managing campus events.
This project was developed as part of BCDE211 Assessment 3, extending an earlier backend/model-based system into a full interactive web application with offline support.

✨ Features
📋 Display all events in a list
➕ Add new events with validation
✏️ Edit existing events
🗑 Delete events
🔍 Search by event name or location
📊 Sort by date, name, or participants
📈 Calculations:
Total events
Total participants
Average participants
📶 Offline support with visible offline banner
💾 Persistent storage using IndexedDB (repository pattern)
⚙️ Tech Stack
React (Vite)
TypeScript
IndexedDB (via custom repository layer)
Service Worker (PWA caching)
HTML / CSS
